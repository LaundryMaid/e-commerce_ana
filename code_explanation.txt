================================================================================
电商数据分析项目 — 代码说明文档
================================================================================

项目结构:
  main.py          数据预处理 + RFM-I 建模 + 用户分层 + ROI 测算
  ab_test.py       A/B测试 三模型对比 (A模型 / B模型 / C模型)
  roi_corrected.py 核心/潜力预算配比敏感性分析
  data/            数据输入输出目录

================================================================================
main.py — 主分析流程
================================================================================

功能:
  读取用户数据 → 特征工程 → RFM-I 建模 → 用户分层 → ROI 测算 → 可视化输出


关键参数:
  total_budget = 10000    总优惠券预算
  coupon_cost = 10        单张券面额
  core_lift = 0.05        核心用户发券后转化提升
  potential_lift = 0.19   潜力用户发券后转化提升
  core_retained_lift = 0.10  核心用户防流失挽回率 (15%→5%)

================================================================================
ab_test.py — A/B 测试三模型对比
================================================================================

功能:
  对比三种发券策略的 ROI 和收益, 展示从初始构想到最终方案的完整过程

三阶段对比 (3x2 图表布局):
  阶段1: 原始虚高版 B 模型
    按"年消费额 × 挽回率"计算防流失价值, 导致 ROI 虚高至 ~556%

  阶段2: 修正后 (无惩罚机制)
    改用"单次 AOV × 挽回率"计算, 对比 A/B/C 三模型

  阶段3: 修正后 (有惩罚机制)
    引入惩罚: 核心占比 0%→60% 时, 潜力收益损失从 50% 线性递减至 5%

模型说明:
  A模型  传统 RFM Top20%, 按综合分取前20%用户发券
  B模型  RFI 80-20, 80%预算给核心用户, 20%给潜力用户
  C模型  RFI 50-50, 50%预算给核心用户, 50%给潜力用户



输出:
  data/ab_test_comparison.png  (3x2 对比图)

================================================================================
roi_corrected.py — 预算配比敏感性分析
================================================================================

功能:
  以 10% 为间距, 测试 0%~100% 核心用户预算占比对 ROI 和收益的影响
  分别在无惩罚和有惩罚两种场景下分析

分析场景:
  场景1: 无惩罚机制
    假设不投核心用户无额外损失, 结果显示潜力占比越高 ROI 越好

  场景2: 有惩罚机制
    模拟核心用户流失对潜力收益的影响, 惩罚从 50%→5% 线性递减
    结果显示最优核心占比约 30% (ROI ~15.9%)

输出:
  data/roi_ratio_no_penalty.png     (无惩罚场景柱状折线图)
  data/roi_ratio_with_penalty.png    (有惩罚场景柱状折线图)
  data/roi_ratio_comparison.png     (两场景 ROI/收益对比图)

================================================================================
数据字段说明
================================================================================

原始字段 (14个):
  User_ID               用户ID
  Age                   年龄
  Gender                性别
  Location              地区
  Income                收入
  Interests             兴趣
  Last_Login_Days_Ago   最近登录天数
  Purchase_Frequency    购买频率
  Average_Order_Value   平均客单价
  Total_Spending        总消费
  Product_Category_Preference 偏好品类
  Time_Spent_on_Site_Minutes 网站停留时间(分钟)
  Pages_Viewed          浏览页数
  Newsletter_Subscription 是否订阅邮件

派生字段:
  Time_Spent_Norm       停留时间标准化 (0-100)
  Pages_Viewed_Norm     浏览页数标准化 (0-100)
  I_Score               意向分 = 0.5*Time_Norm + 0.5*Pages_Norm
  Friction              阻力系数 = 浏览页数 / (购买频率+1)
  L_Score               忠诚度评分 (1/2/3)
  Income_Level          收入分层 (Low/Medium/High)
  R_Score               最近性标准化 (反向, 0-100)
  F_Score               频率标准化 (0-100)
  M_Score               金额标准化 (0-100)
  RFM_Score             RFM 综合分 = 0.2*R + 0.3*F + 0.5*M
  I_Weight              意向权重 = I_Score / 500
  Final_Score           最终综合分 = RFM_Score * (1 + I_Weight)
  User_Segment          用户分层标签

================================================================================
用户分层体系
================================================================================

基础分层 (按 R/F/M 分):
  重要价值用户   R>60, F>60, M>60
  重要发展用户   R>60, M>60, F<40
  重要保持用户   R<40, F>60, M>60
  重要挽留用户   R<40, M>60
  一般发展用户   R>60, F>40, M<40
  一般维持用户   R>60, F<40, M<40
  低价值用户     R<40, F<40, M<40
  一般用户       其余

RFI 修正分层 (叠加 I_Score/Friction/Income):
  高潜沉睡用户   低价值/维持 + 高收入 + I>60
  纠结土豪       高收入 + I>70 + F<40 + M<50
  犹豫型潜力用户  一般维持/发展 + I>80 + Friction高
  隐形活跃者     低收入 + I>70 + F<40
  高潜流失客     高收入 + R<40 + M>50
  核心VIP        M>70 + F>70 + I>60
  羊毛党/低值    低收入 + I<40 + M<40

核心用户池: 核心VIP + 重要价值用户
潜力用户池: 纠结土豪 + 高潜沉睡用户 + 犹豫型潜力用户 + 高潜流失客
